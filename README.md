# Experiment 16: Student details using structure

C programming lab experiment based on the MIT ADT University C Programming Lab Manual (A.Y. 2026–2027).

## Compile

```bash
gcc -std=c11 -Wall -Wextra -pedantic main.c -o program
```

## Run

```bash
./program
```

On Windows, run `program.exe` after compiling.
